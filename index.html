Introduction

JavaScript is a cross-platform, object-oriented scripting language. It is a small and lightweight language. Inside a host environment (such as a web browser), JavaScript can be connected to the objects of its environment to provide programmatic control over them.

JavaScript contains a standard library of objects, such as Array, Date, and Math, and a core set of language elements such as operators, control structures, and statements.

Core JavaScript can be extended for a variety of purposes by supplementing it with additional objects; for example:

  • Client-side JavaScript extends the core language by supplying objects to control a browser and its Document Object Model (DOM).
  • Server-side JavaScript extends the core language by supplying objects relevant to running JavaScript on a server.

JavaScript and Java

JavaScript and Java are similar in some ways but fundamentally different in others. The JavaScript language resembles Java but does not have Java's static typing and strong type checking.

JavaScript follows most Java expression syntax, naming conventions and basic control-flow constructs which was the reason why it was renamed from LiveScript to JavaScript.

  • Java is an object-oriented programming language designed for fast execution and type safety.
  • JavaScript is an embedded client-side scripting language focused on dynamic interactivity.

In contrast to Java's compile-time system built on classes, JavaScript supports a runtime system based on a small number of data types representing numeric, boolean, and string values.

Hello world

To get started with writing JavaScript, you can open the Scratchpad and write your first "Hello world" JavaScript code:

function greetUser(name) { return "Hello " + name; }

The code above declares a function that takes a name parameter and returns a greeting string. You can invoke this function in any active browser console.

Understanding how basic functions operate gives you the foundation needed to build more complex logical applications and interactive web pages.

  • Functions encapsulate reusable blocks of logic.
  • Parameters allow passing dynamic arguments into functions.
